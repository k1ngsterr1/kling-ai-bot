## API Endpoints

### POST /payment/create

Создает новый платеж

### POST /payment/callback

Обрабатывает уведомления от Robokassa

### GET /payment/success

Страница успешной оплаты

### GET /payment/fail

Страница неудачной оплаты

## Workflow оплаты

1. Пользователь выбирает пакет в боте
2. Создается запись о платеже в БД
3. Генерируется URL для оплаты в Robokassa
4. Пользователь переходит на оплату
5. После оплаты Robokassa отправляет уведомление на callback
6. Система проверяет подпись и зачисляет токены
7. Пользователю отправляется уведомление в Telegram

## Команды бота

- `/balance` - показать баланс и пакеты
- Inline кнопки для покупки пакетов

## Безопасность

- Все подписи проверяются через MD5 хеш
- Используются отдельные пароли для создания платежей и проверки уведомлений
- Все платежи логируются
